# Quick View Version 2 下一阶段图片制作计划

更新日期：2026-10-02

## 1. 本阶段目标

在已经确认的桌面草地世界上，继续制作能够支持完整滚动叙事的视觉资产。当前任务不是重新生成世界母版，而是补齐 Desk / CRT、Carousel、Newsstand 三组场景物件，并在桌面效果确认后制作移动端版本。

整体关系保持：

```text
Quick View = 明亮、安静、轻微反常的外部草地世界
Explore    = 进入入口小屋后的内部探索空间
```

梦核规则保持克制：云中垂落的窗帘、窗帘中的金鱼、漂浮入口小屋属于同一个异常意象。新物件不再添加新的世界规则。

## 2. 已锁定资产：不要重新生成

当前桌面视觉母版及分层资产已经确认，画布均为 `1672 × 941 px`：

```text

├─ base-sky-meadow.png
├─ cloud.png

```

这些资产决定后续图片的光线、颜色、清晰度和摄影质感。下一批图片必须与其匹配，不再修改以下内容：

- 深蓝偏青的干净天空
- 暖阳照射的橄榄绿色草坡
- 光线主要来自画面左上方
- 奶油白半透明窗帘
- 橙色金鱼
- 白色灰泥墙、红棕屋顶的普通入口小屋
- 真实摄影基础上的安静超现实感

禁止重新加入：

- 胶片颗粒、灰尘斑点和扫描线

- 浓雾、暗角和恐怖照明
- 水波纹、鱼影及其他水下效果
- 额外漂浮建筑、门框、吊灯或地面异常
- 新的金鱼、窗帘或奇幻生物

## 5. 第一批：Desk / CRT

### 场景作用

Desk / CRT 对应 About，是最先进入草地世界的 Explore 物件。它代表个人工作空间，但不能承载 About 正文；ID 卡和介绍文字继续使用现有网页排版。

### 造型要求

- 参考 `02-desk-crt-region.png` 的桌子、CRT 轮廓和主要配色。
- 保留能够让用户认出 Explore 物件的标志性细节。
- 桌子完整落在草地上，透视必须与当前草坡一致。
- CRT 可以亮起，但画面只显示柔和的浅色或模糊色块，不显示文字、图标和具体 UI。
- 不添加椅子、人物、文件堆、植物、插座或电线等新主体。
- 外观保持普通，反常性来自室内工作桌出现在草地上。

### 光线和镜头

- 暖阳从左上方照射。
- 高光颜色与现有云、窗帘和房屋一致。
- 阴影向右下方延伸。
- 相机高度接近成人站立视角。
- 等效焦段建议 `50–65 mm`，减少广角变形。
- 景深保持克制，桌子和 CRT 主体均应清晰。

### 交付资产

```text
desk-crt-cutout.png
desk-crt-shadow.png
desk-crt-screen-glow.png   # 可选
desk-crt-reference.jpg     # 带草地和天空的效果预览，仅用于确认
```

要求：

- Cutout 使用透明背景，包含桌子和 CRT，不包含草地与天空。
- Shadow 单独透明输出，不烘焙进主体。
- Glow 只有 CRT 屏幕光，边缘柔和，不包含主体。
- 主体长边至少 `1600 px`。
- Cutout、Shadow、Glow 使用相同紧边画布、相同坐标和相同透明边距。

## 6. 第二批：Carousel

### 场景作用

Carousel 从 Experience 后段开始在远处出现，在 Projects 阶段逐渐清晰。它承担 Quick View 与 Explore 之间最明确的物件呼应。

### 造型要求

- 参考 `03-carousel-region.png` 的整体轮廓、顶棚、立柱、马匹与灯带。
- 保留探索版木马最容易识别的颜色关系和装饰结构。
- 输出完整木马，不要让顶棚或底座被画布裁掉。
- 不添加游乐园、围栏、售票亭、人物、气球或其他设施。
- 白天环境下灯带允许发出很弱的暖光，不能像夜景霓虹灯。
- 不需要做破败、废弃或恐怖处理。

### 光线和镜头

- 暖阳从左上方照射。
- 等效焦段建议 `55–70 mm`。
- 视角略低于木马顶棚，但不使用夸张仰拍。
- 主体整体清楚，避免强烈浅景深。
- 阴影方向与入口小屋一致，向右下方延伸。

### 交付资产

```text
carousel-cutout.png
carousel-shadow.png
carousel-lights.png        # 可选，只有灯光
carousel-reference.jpg     # 带草地和天空的效果预览，仅用于确认
```

要求：

- 主体长边至少 `1800 px`。
- 透明边缘必须保留顶棚细节、细立柱和马腿，不出现黑边或白边。
- Lights 只包含微弱暖光，不包含木马实体。
- Cutout、Shadow、Lights 使用相同画布与坐标。

## 7. 第三批：Newsstand

### 场景作用

Newsstand 在 Projects 后段进入画面，并在 Contact 附近与漂浮入口小屋共同出现。它是进入 Explore 前最后一个内部物件提示。

### 造型要求

- 参考 `04-newsstand-region.png` 的亭体轮廓、开口、招牌和陈列结构。
- 保留 Explore 报刊亭最容易识别的颜色和结构。
- 报刊、杂志和纸张只作为小面积纹理，不生成可读文字。
- 不添加店员、顾客、街道、路灯、自行车或城市环境。
- 报刊亭落在草地上，不能漂浮。
- 结构完整，底部、顶棚和侧边不能被裁切。

### 光线和镜头

- 暖阳从左上方照射。
- 等效焦段建议 `50–65 mm`。
- 相机高度接近成人站立视角。
- 正面略带侧角，使开口和侧面同时可见。
- 内部可以略暗，但不能成为黑洞。

### 交付资产

```text
newsstand-cutout.png
newsstand-shadow.png
newsstand-interior-glow.png # 可选
newsstand-reference.jpg     # 带草地和天空的效果预览，仅用于确认
```

要求：

- 主体长边至少 `1600 px`。
- 不生成可读报刊标题、品牌名称或乱码。
- Cutout、Shadow、Glow 使用相同画布与坐标。

## 8. 桌面资产统一技术规范

### 主体文件

- 工作文件：PNG，RGBA 透明背景。
- 色彩空间：sRGB。
- 位深：8 bit。
- 主体边缘保留真实半透明像素。
- 不使用纯黑或纯白底冒充透明背景。
- 不在主体图中烘焙阴影、光晕、颗粒或色彩遮罩。

### 构图方式

生成阶段可以先制作带草地与天空的 Reference JPG，用于确认物件是否属于当前世界。确认后必须输出独立透明主体。

透明主体采用紧边画布，不需要扩展为 `1672 × 941 px`。网页端会根据最终排版决定位置和尺寸，这样能降低文件体积并提供更大的动画自由度。

### 一致性要求

三组物件必须共享：

- 同一太阳方向
- 同一暖色高光
- 同一阴影软硬程度
- 同一真实摄影清晰度
- 相近的透视和观察高度
- 干净、连续、没有生成斑点的表面

三组物件不能分别呈现日系胶片、童话插画、3D 渲染和复古照片等不同风格。

## 10. 移动端批次

桌面三组物件接入并确认以后，再制作移动端。移动端不能直接裁切桌面图片。

### 移动母版

```text
尺寸：1440 × 2560 px
比例：9:16
```

先制作一张移动端完整效果图，确认以下关系：

- 云和窗帘位于画面上部，并为正文留下竖向阅读区域。
- 金鱼仍然在窗帘内部，不散落到整个天空。
- 漂浮房屋位于中下部，但不压住章节内容。
- 草地占画面下部约 28%–35%。
- 状态栏、浏览器工具栏和底部安全区附近没有关键物件。

## 11. 每批验收流程

每个物件都按同一流程进行：

1. 先看 Reference JPG，确认造型、光线和尺度。
2. 只修改主体问题，不重新设计整个草地世界。
3. 确认后输出 Cutout、Shadow 和可选 Glow。
4. 检查透明边缘是否有白边、黑边和残留背景。
5. 接入 Version 2 桌面页面。
6. 在首屏、章节中段和章节交界处检查实际尺度。
7. 只有网页效果确认后才进入下一组物件。

## 12. 单项验收清单

- [ ] 第一眼能认出它与 Explore 中对应物件有关
- [ ] 光线方向与当前草地母版一致
- [ ] 没有新增不必要的主体和故事元素
- [ ] 没有颗粒、斑点、乱码和重复 AI 纹理
- [ ] 没有黑边、白边和残留背景
- [ ] 主体、阴影、光效能够独立控制
- [ ] 缩小到网页实际尺寸后仍能识别轮廓
- [ ] 不依赖文字解释也能理解物件是什么
- [ ] 不遮挡 Quick View 的中央内容安全区
- [ ] 不把整体风格带向恐怖、童话或游戏渲染
