《手账书》内页排版规范

  
    适用文件：`book-coil-flip-demo.html`\
    版本：v1.0（2026-09-26 首次成文，数值全部提取自当前源码实测）\
    目的：统一内页版式标准，锁定核心参数，防止后续编辑把版式改乱。\
    阅读约定：标注 🔒 的为 P0 锁定项，改动必须走第 11 节审批流程；标注 ⚠️ 的为 P1 谨慎项。
  

  1. 基准与适用范围

  本规范约束书页内页（`.pg` 页面画布及其内部所有版式），不约束书外 HUD（页码按钮、侧签、挂饰、提示语）。

  所有内页内容是数据驱动的：改内容 → 改 JS 里的 `PAGE` / `CHAPTERS` / `FACES` 数据字符串；改版式 → 改对应 `.pg.c-xxx` / `.sec-in` 等 CSS 类。禁止在 HTML 字符串里写内联样式绕过规范。

  1.1 页面画布（🔒 P0）

```css
  :root{
    --pw:350px;      /* 单页宽 —— 锁定 */
    --ph:470px;      /* 页高   —— 锁定 */
    --paper:#f8f7f1; /* 纸色   —— 锁定 */
    --ink:#39412e;   /* 墨色   —— 锁定 */
  }
  ```

  单页有效面积 350 × 470 px，宽高比 ≈ 0.745（近 B6）。

  所有内页排版以这两个值为前提，任何"页边距、栏宽、图宽"的数值都基于 350px 宽推算，不允许假设其他页宽。

  1.2 每篇主题色变量（🔒 P0 机制，色值可换）

  每章通过 `--ac / --acd / --aco` 三元组定义本篇 tone（主色 / 深色 / 对比色）。内页所有强调元素（色签、小标题左线、章节侧签、成果条、chip）只允许引用这三个变量，不允许硬编码新颜色。

  5. 字号阶梯（🔒 P0 体系，⚠️ P1 单值）

  字号是阶梯制，以下为全站实际使用的完整阶梯（px）。新增文字必须就近落在阶梯上，不允许出现 10.2px、13.7px 这类阶梯外的值。

```

          36        封底 ftitle
          29        目录页标题
          25        文字页大字引言
          23        扉页主标题
          21 / 20   硫酸纸编号 / 篇首大标题
  大标题  19        梦核页诗句
          17 / 16.5 板块序号 / 复盘副题
          16        竖签标题、目录行章节名
          15.5      板块页标题
          15        目录 kicker、扉页星
  小标题  14.5 / 14 硫酸纸图注 / 报头副题
          13        日期行、竖签式小节题
          12.5 / 12 机构行 / 图注、标题分隔条
  辅助    11.5 / 11 副题、图注基线字号
          10.5 / 10 chip 标签 / 引子
  正文    9.8       板块摘要 sum
          9.5       ★ 正文标准字号（.blk .txt / .rev-txt / secv .txt）
          9.4       成果条 result
  装饰    9 / 8.5 / 8.4 / 8   图注卡 / 标记 / 贴纸说明 / 页码
  ```

  正文标准：`9.5px + line-height 1.8 + 两端对齐`，全站所有成段文字一律如此（🔒 P0）。正文小于 9.5px 只允许出现在装饰性说明（≤9.4px 档）。

  层级差：相邻两级至少差 1.5px 或跨档引用，靠字号区分层级时禁止用 0.5px 级差硬凑。

  对齐规则：

  板块页、目录页、硫酸纸：内容左对齐为主轴；图注（`.cap`）分两派——照片页图注右对齐、拍立得图注居中，不得互换。

  封底、扉页、梦核页：整页居中构图。

  页码 `.pgno`：右页 `right:22px; bottom:14px`，左页（bside）镜像到 `left:22px`（🔒 P0，写死在 CSS，别在内容里另写页码）。

  拍立得、贴纸、chip 允许 ±2.4° 内的装饰性微旋转（`.pol` -2.4°、`.st` -2°/+1.6°、chip -1.2°/+1.4°、成果条 0.4°），新做贴纸元素旋转角取值不超过 ±2.5°，且偶数项与奇数项方向相反。

  留白原则：

  内容不满一页时用 `justify-content:center`（文字/扉页）或 `margin-top:auto`（成果条、目录脚注）消化，禁止用加大 margin 硬塞。

  一页最多 3 个小节（blk）+ 1 条成果条；超过就该拆页，不是缩字号。

  底部 32px 内边距区域是"页码保护区"，任何内容不得侵入（页码本身除外）。

  左右不对称留白只允许出现在：封面/封底 56px 点带侧、secv 右签 48px 让位侧。其余版式左右边距必须相等。

  10. 色彩与阴影（⚠️ P1）

  纸面文字只用：`--ink #39412e`（主）、`#414836`（正文深灰绿）、`--acd`（本篇深 tone）、白系 `#fffdf6/#fffdf7`（贴纸底）。

  正文色 `#414836` 全站统一，opacity 介于 `.62 ~ .8` 的灰阶靠 `opacity` 实现，不另调色。

  阴影统一走"绿灰投影"：`rgba(45,55,35,.12~.18)` 或 `rgba(45,65,50,.07~.17)`；封面/封底深色页内不叠加新阴影色。

  贴纸底色 `#fffdf6`、卡片描边 `rgba(90,75,40,.25)` 为固定值。
